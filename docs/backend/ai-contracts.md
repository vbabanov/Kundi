# AI Orchestration Contracts (Verified)

## Pipeline components (implemented as packages)
- `context_builder`
- `persona_policy`
- `pedagogy_policy`
- `moderation`
- `response_renderer`
- `tts`
- `avatar_cues`

## Input contract
- `mode`: `tutor` or `general_chat`
- `student_id`
- `grade_level` (optional; defaults when absent)
- `text`
- `history[]`

## Output contract
- `text`
- `audioUrl`
- `audio_status` (`ready` | `unavailable`)
- `visemes[]`
- `avatar_emotion`
- `gesture_tags[]`
- `pedagogy_flags`
- `behavior`:
  - `mode`
  - `grade_level`
  - `grade_band`
  - `persona_tone`
  - `persona_style`

## Current behavior
- Tutor/general mode separation is active.
- Persona policy adapts by grade band.
- Moderation gate can block unsafe content.
- TTS URL and avatar cues are generated by dedicated components.
- LLM/TTS are adapter-driven with deterministic fallback behavior.
- When TTS is unavailable:
  - `audio_status=unavailable`
  - `audioUrl=''`
  - viseme/gesture package is not emitted as if playback is available.

## Known limitations
- Real LLM/TTS providers require external credentials and endpoint hookup.
- Full policy tuning requires product calibration and telemetry.
